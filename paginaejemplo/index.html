Comenzar Tutorial

¿Por qué esta arquitectura?

Ventajas clave de combinar la potencia del hosting estático en la nube con la integración continua de GitHub.

CI/CD Automático

Cada `git push` a la rama principal desencadena una construcción y despliegue directo mediante GitHub Actions.

SSL Gratis y CDN global

Azure asigna automáticamente certificados HTTPS seguros y distribuye el contenido a través de una CDN global.

Entornos de Staging

Los Pull Requests generan previsualizaciones automáticas con su propia URL aislada antes de fusionar cambios a producción.

Pasos para Desplegar en Azure

1

Sube el código a GitHub

Crea un repositorio público o privado e incluye este archivo `index.html` en la raíz.

2

Crea el recurso en Azure Portal

Busca Static Web Apps en Azure Portal, haz clic en Crear y vincula tu cuenta de GitHub.

3

Configura el Build Preset

Selecciona Custom o HTML y deja el `App location` como `/`. ¡Azure creará el workflow de GitHub Actions automáticamente!
